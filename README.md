# NJU IE Course Guide

[本网站](https://njuwallspider.github.io/IECourseGuide/) 灵感直接来源于[CS自学指南](https://csdiy.wiki/)，目的是为南京大学工业工程系 (**I**ndustrial **E**ngineering) 的学子提供全方位的学习支持，其中大一的基础课内容也适合绝大多数理工科。

本书内容包括：

- 南京大学的工业工程（IE）在干什么。

- 学习 IE 要用到的基本工具：如Git、LaTex、Gurobi等等。

- **南大IE所有课程资料汇总**：把NJUIE所有课程资源分门别类进行汇总，包含学习内容、任课老师、课程教材、课程学习建议
、往年卷、补充资料等，供大家学习参考。

- 经典书籍推荐：推荐IE领域的必看好书。

## 共同完善本指南（无需 fork）

网站新增了**站内投稿入口**，任何同学都可以直接提交补充资料、增补介绍或纠错，不用 fork、不用装环境、不用懂 git：

1. 打开 [提交修改](https://njuwallspider.github.io/IECourseGuide/提交修改/) 页面，选择投稿类型并填写内容；
2. 点击「生成并提交」后会打开一个已填好的 GitHub Issue，把 PDF / 图片拖进编辑框后提交即可；
3. 维护者在 Issue 里看到**变更预览**，批准后机器人自动修改仓库并重新发布网站，几秒后新内容就会出现在页面上。

> 需要登录 GitHub 账号；单个附件不超过 25 MB。不想注册 GitHub 也可以继续用邮箱投稿。
>
> 维护者请看 [.github/MAINTAINER_GUIDE.md](.github/MAINTAINER_GUIDE.md)；投稿协议（Issue 元数据格式、落库规则）见 [.github/contribution-schema.md](.github/contribution-schema.md)。

## 为什么写这本书

这本书的目的就是要建立南大IE**自己的学习指南**。每个人都可以把自己的学习资源与方法分享，再由专人分门别类详细汇总，让知识与经验平等且高效地惠及每一个人。

【注】本网站内容借鉴了[浙大图灵班学习指南](https://zju-turing.github.io/TuringCourses/readings/)。
